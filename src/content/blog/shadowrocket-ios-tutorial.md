在苹果 iOS 生态中，**Shadowrocket（俗称“小火箭”）** 无疑是普及度最高、性价比最强且最老牌的代理利器。凭借其一次付费终身使用、协议覆盖全面（支持 Shadowsocks、Vmess、Vless、Trojan、Hysteria 2 等）、内存占用轻量以及卓越的后台省电机制，成为了几乎所有苹果用户的装机第一选择。

本文将手把手演示如何在 iPhone 与 iPad 上完成小火箭的正规安装、机场节点一键导入、规则模式分流设置以及常见故障排查。

## 一、下载安装与海外 Apple ID 获取

由于苹果应用商店的政策限制，Shadowrocket 未在大陆区 App Store 上架，需要通过海外地区（如美区、港区、日区等）的 Apple ID 进行安装。

> **官方正规下载通道**：
> - 官方 App Store 地址：[Shadowrocket on the App Store](https://apps.apple.com/app/shadowrocket/id932747118)
> - 定价：通常为 $2.99 美元（一次购买，同账号下 iPhone/iPad 终身通用）。

### 安全避坑注意事项：
1. **切勿在系统设置中登录他人 iCloud**：仅在 **App Store** 登录海外账号下载软件，切勿在 iPhone 的「设置」主界面登录陌生账号，以防手机被恶意远程锁机（开启“查找我的 iPhone”）。
2. **警惕第三方山寨仿冒版**：App Store 中存在名称和图标极为相似的克隆软件，认准开发者名称为 **Shadow Launch Technology Limited**，避免付费买到山寨假货。

如果你暂时没有海外 Apple ID，也可以在我们的 [全平台科学上网客户端指南](/clients) 中查看支持国区直接下载的 **Nextin**（支持输入推荐机场专属码直连）或 **Clash Mi**。

## 二、导入机场节点订阅链接

购买优质机场服务（如 [2026 机场推荐天梯榜](/ranking) 中的 [神行加速](/blog/2026-top-airports-recommendation/)、[大佬云](/blog/2026-top-airports-recommendation/) 或 [云界线](/blog/2026-top-airports-recommendation/)）后，即可将节点一键同步到小火箭：

### 方式 A：订阅链接一键导入（最推荐）
1. 登录机场用户中心，找到 **“小火箭/Shadowrocket 订阅”** 或 **“通用订阅链接”** 并复制；
2. 打开 Shadowrocket，点击右上角的 **「+」** 号进入添加节点页面；
3. 将 **「类型 (Type)」** 切换为 **`Subscribe`**（订阅）；
4. 在 **「URL」** 一栏粘贴刚复制的订阅地址；
5. 在 **「备注」** 中填入机场名称（例如“神行专线”），点击右上角 **「完成」**；
6. 软件会自动向服务器请求并拉取所有节点列表。

### 方式 B：屏幕扫码导入
如果电脑屏幕上已打开机场后台的订阅二维码：
1. 点击小火箭首页左上角的 **「扫一扫」** 按钮；
2. 对准电脑屏幕上的订阅二维码，扫描后自动保存并立即更新节点。

## 三、核心运行模式设置：拒绝全局卡顿

小火箭底部导航栏切换至 **「配置」** 页面，核心注意全局路由的切换：

1. **配置模式 (Config / 推荐日常默认开启)**：
   - 内置强大的智能分流规则：访问国内网站（百度、微信、网易云、淘宝等）走本地蜂窝/Wi-Fi 直连，绝不消耗机场流量；
   - 访问海外被屏蔽服务（Google、YouTube、ChatGPT、X/Twitter）自动走选定代理节点。
2. **代理模式 (Proxy / 全局代理)**：
   - 手机上的所有网络流量强制走代理出口。会导致访问国内 App 变慢或提示异地登录，仅在排查网络故障时临时测试使用。
3. **直连模式 (Direct)**：
   - 所有流量不走代理，相当于关闭翻墙。

**操作提示**：在首页中间的 **「全局路由」** 选项中，请务必确认勾选为 **「配置」**。

## 四、节点延迟测速与开启连接

1. 在首页节点列表中，点击 **「连通性测试」**，软件会对列表中所有节点并发发送测试请求；
2. 观察节点右侧的延迟毫秒数（ms），显示绿色数值（如 40ms~120ms）代表节点通畅，黄色为中等延迟，若显示超时或不可达则为红色；
3. 点击选中一个延迟稳定、名称带有 **“IEPL专线”**、**“香港 01”** 或 **“日本 01”** 的节点，节点左侧出现黄/橙色圆点标记表示当前选定；
4. 将首页顶部的第一行开关 **「未连接」** 滑动开启；
5. *首次运行提示*：系统会弹出 iOS 官方弹窗：“Shadowrocket 想添加 VPN 配置”，点击 **「允许」**，并验证 Face ID / Touch ID 或输入手机锁屏密码；
6. 状态栏顶部出现 **[VPN]** 标识，即代表科学上网代理已成功运行！

## 五、进阶技巧：防 DNS 泄露与流媒体解锁调优

1. **开启 HTTPS 解密与本地 DNS 劫持防护**：
   - 切换到 **「设置」** -> **「DNS」**，建议将首选 DNS 设置为公共安全 DNS（如 `1.1.1.1` 或 `8.8.8.8`），备用 DNS 可添加 `223.5.5.5`（阿里 DNS 用于解析国内域名），杜绝运营商 DNS 污染。
2. **针对 ChatGPT / Netflix 的策略分流**：
   - 如果遇到打开 ChatGPT 提示 Access Denied，可以通过我们的 [网络测速与节点检测工具箱](/tools) 检查当前节点的出口 IP 属性；
   - 在小火箭中选择标注有“原生”或“住宅”属性的节点，或在 [原生住宅IP与流媒体解锁深度指南](/blog/netflix-chatgpt-unlock-native-ip/) 中获取更多风控规避方案。

## 六、常见问题解答 (FAQ)

### Q1: 开启小火箭后，微信或国内网页打不开了怎么办？
**答**：这通常是因为误将「全局路由」设置为了「代理 (Proxy)」，导致国内流量全部绕道海外。请在小火箭首页将全局路由切换回 **「配置 (Config)」**。如果仍然不行，前往「配置」页面点击默认规则右侧的感叹号，选择 **「重置为默认配置」** 即可恢复正常。

### Q2: 节点全部变红提示超时，但别人用正常，怎么排错？
**答**：按照以下三个步骤自查：
1. **检查 iPhone 系统时间**：iOS 系统时间与网络标准时间偏差超过 1 分钟会导致 TLS 握手证书验证失败，前往「设置」->「通用」->「日期与时间」开启“自动设置”；
2. **更新订阅链接**：向左滑动机场订阅卡片，点击「更新」获取最新可用节点；
3. **切换网络环境**：若在公司 Wi-Fi 下被网络管理员封锁了代理端口，尝试切换为手机 4G/5G 蜂窝数据重试。

### Q3: 为什么小火箭测速显示 60ms，但看视频依然卡顿？
**答**：小火箭首页的连通性测试仅代表 TCP 握手 Ping 值，并不等同于节点实际下载带宽。如果遇到卡顿，说明该节点正在经历晚高峰拥堵。建议在 [高性价比备用机场盘点](/blog/cheap-value-backup-airports/) 中配置一个不限时备用节点，或者选择 [2026 机场天梯榜](/ranking) 中晚高峰实测 500 Mbps 上下的专线服务商。
