> **核心导读**：老版 Clash for Windows 早已全面停更。目前 Windows 与 macOS 电脑上最稳定、界面最干净、内存占用最低的替代工具就是 **Clash Verge Rev**。很多初次接触的新手会被各种专业术语绕晕，本文摒弃繁复的技术黑话，用通俗直白的大白话教你一步步完成安装、导入订阅并开启翻墙。

## 一、极简 3 步速成法（急用先看这里）

如果你刚买好机场套餐，想在 3 分钟内立刻用上外网，只需要依次完成以下 3 步：

1. **下载安装**：下载对应电脑系统的安装包并安装打开；
2. **导入订阅**：去机场后台复制“Clash 订阅链接”，粘贴到软件左侧「订阅」里点击保存；
3. **开启代理**：点击左侧「代理」选一个绿色的香港或日本节点，再打开左下角的「系统代理」开关，即可直接访问 Google 和 YouTube。

下面为你拆解每一步的具体操作细节与注意事项。

## 二、第一步：下载与安装（认准版本别下错）

请务必从官方开源项目下载正规安装包，切勿在普通搜索引擎上随便下载第三方捆绑了流氓推广甚至病毒的所谓“汉化破解版”。

- **官方开源项目地址**：[clash-verge-rev on GitHub Releases](https://github.com/clash-verge-rev/clash-verge-rev/releases)

### 1. Windows 用户怎么选？
在官方下载列表中，找到以 `.exe` 结尾的文件：
- 绝大多数普通电脑用户：直接下载 `Clash.Verge_x.x.x_x64_setup.exe`；
- 下载完成后双击运行，一路点击“下一步”直到安装完成。

### 2. Mac 苹果电脑用户怎么选？
根据你的 Mac 处理器型号选择对应的 `.dmg` 镜像文件：
- 近几年购买的 M 系列芯片机型（M1 / M2 / M3 / M4）：下载名称中带有 `_aarch64.dmg` 的版本；
- 较早的 Intel 处理器机型：下载名称中带有 `_x64.dmg` 的版本；
- 下载后双击打开，将软件图标拖入“应用程序 (Applications)”文件夹即可。

如果你同时需要在手机端配置科学上网，可同步参考我们的 [Shadowrocket iOS 小火箭教程](/blog/shadowrocket-ios-tutorial/) 或 [v2rayN 与 v2rayNG 双端配置指南](/blog/v2rayn-v2rayng-setup-guide/)。

## 三、第二步：把界面切换为简体中文

Clash Verge Rev 安装完毕首次打开时，默认界面可能是英文。两步即可换成中文：

1. 点击软件左侧导航栏底部的齿轮图标 **「Settings」**（设置）；
2. 找到 **「Verge Setting」** 下方的 **「Language」**（语言）选项，在下拉框中选择 **「简体中文」**；
3. 界面会立即刷新变为中文，后续所有操作就一目了然了。

## 四、第三步：导入机场订阅链接

这是最核心的一步，订阅链接就是让软件拉取可用节点列表的“钥匙”。

1. **获取链接**：登录你购买的机场官网后台（例如从我们的 [2026 优质机场天梯榜](/ranking) 挑选的 [神行加速](/blog/shenxingjiasu-review/)、[大佬云](/blog/dalaoyun-review/) 或 [云界线](/blog/yunjiexian-review/)），找到 **「一键导入订阅」** 按钮，点击复制 **「Clash 订阅地址」**；
2. **粘贴保存**：打开 Clash Verge Rev，点击左侧菜单栏的 **「订阅」**；
3. **录入软件**：把刚才复制的订阅链接粘贴到顶部的长输入框中，点击右侧的 **「保存」**（Save）；
4. **加载配置**：软件会自动从服务器拉取节点，列表中会出现该机场的卡片；
5. **激活选用**：**用鼠标左键单击一下这个机场卡片**。卡片外围出现一条**蓝色高亮边框**，表示当前已经成功启用了该机场的节点配置。

## 五、第四步：选择节点并开启代理

配置文件载入完成后，只需选定节点并打开总开关：

### 1. 选择分流模式
点击左侧菜单栏的 **「代理」**：
- 顶部通常有三个模式开关：**规则 (Rule)**、**全局 (Global)**、**直连 (Direct)**；
- **新手务必选择「规则 (Rule)」模式**：这个模式最聪明，访问国内软件（微信、淘宝、百度、B站）时自动走你本地宽带，不浪费翻墙流量；只有在打开海外网站（Google、YouTube、ChatGPT）时才会自动调用代理。

### 2. 测速与挑选节点
1. 在代理页面右上角，找到一个类似 **Wi-Fi 波纹** 的小图标（测速按钮），点击它；
2. 软件会测试所有节点的网络响应时间，节点右侧会显示具体的毫秒数字（例如 `35ms`、`52ms`）；
3. **选一个显示为绿色且延迟较低的节点**（推荐香港、日本、新加坡地区），鼠标单击即可选中。

### 3. 打开代理开关
- 在软件界面的左下角或左侧「设置」页面中，找到 **「系统代理 (System Proxy)」**；
- 把这个开关**拨到开启状态**。
- 此时打开电脑浏览器访问 Google，即可顺畅打开，恭喜你已经成功连接。

## 六、什么是 TUN 模式？新手需要开吗？

很多新手常在群里看到别人讨论“开 TUN 模式”，这里用大白话解释：

- **普通用户看网页、看 YouTube**：**只开「系统代理」就完全够用了**，不需要开 TUN 模式；
- **什么情况下需要开 TUN 模式？**
  - 你在玩外服电脑游戏（Steam 联机、Apex 等）；
  - 你是程序员，在命令行终端（CMD / PowerShell / Git clone / Docker）中下载依赖包老是报错超时；
  - 某些特殊软件不遵循浏览器的系统代理协议。
- **开启方法**：点击左侧「设置」，找到「TUN 模式」开关打开。首次开启 Windows 会弹出一个权限确认框，点击“是”允许安装虚拟网卡即可。开启 TUN 后，整台电脑所有软硬件发出的网络请求都会被无缝加速。

## 七、两个最关键的小白避坑守则

1. **不用时先关开关，再退出软件**：
   电脑关机或准备关闭软件前，务必先在软件里把 **「系统代理」开关关闭**，然后再退出软件。否则可能导致下次开机时浏览器提示“无法连接到代理服务器”。
2. **节点打不开了先更新订阅**：
   如果哪天突然所有节点连不上，先去「订阅」页面，鼠标右键点击机场卡片选择 **「更新」**。机场服务商更新了被封锁的节点后，刷新一次就能重新恢复。更多防跑路与避坑建议可参阅我们的 [新手科学上网防坑实用指南](/blog/avoid-airport-scams-guide/)。

## 八、新手最常遇到的 4 个问题与秒解法（FAQ）

### Q1: 关了软件之后，电脑突然连百度和微信都上不去了？
**答**：这是最常见的新手问题。原因是在退出软件前没有关掉系统代理，导致系统网络设置里残留了代理端口。
**秒解法（Windows 10/11 通用）**：
1. 按键盘上的快捷键 `Win + i` 打开系统「设置」；
2. 点击「网络和 Internet」-> 左侧或右侧的「代理」；
3. 找到「手动设置代理」下方的 **“使用代理服务器”**，把它**关闭**；
4. 重新刷新浏览器，本地网络即可瞬间恢复正常。

### Q2: 订阅链接粘贴进去点击保存，提示“Network Error”或下载失败？
**答**：通常是因为你的本地运营商（移动或电信）对机场订阅域名进行了 DNS 干扰。
**解决方法**：
1. 先用手机开一个 4G/5G 个人热点让电脑连接，再在软件里点一次“更新订阅”，拉取成功后再切回原本的 Wi-Fi；
2. 或者在 Clash Verge Rev 的「设置」中，勾选 **“使用系统代理更新订阅”** 后重试；
3. 也可在我们的 [实用网络测速与节点检测工具箱](/tools) 中检查本地 DNS 是否有泄露与解析异常。

### Q3: 为什么列表里有些节点测速全是超时（红色或 Timeout）？
**答**：节点测速超时说明该服务器正在维护或被本地运营商阻断。只要列表里有其他绿色的香港、日本或新加坡节点可用即可正常上网。如果需要高可用不掉线的节点保障，建议在 [高性价比与备用不限时机场推荐](/blog/cheap-value-backup-airports/) 中常备一个低门槛备用节点。

### Q4: 网页能正常打开，但登录 ChatGPT 提示 Access Denied 或 1020 错误？
**答**：OpenAI 对数据中心机房 IP 审查极严。如果遇到拦截，请在代理列表中切换带有“原生”或“住宅”字样的专线节点，并参考我们的 [原生住宅IP与流媒体解锁深度指南](/blog/netflix-chatgpt-unlock-native-ip/) 测试节点的纯净度。
